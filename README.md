## The word

**unread**

One word, the word an ex would use to describe you: every message left
unread, every apology never even opened. It stings because it is true,
it lands instantly, and anyone who has ever been left on read knows it.

## How it works

`main.ts` writes the word to `/output/entry.txt` and self-checks the
competition gate before writing: exactly one plain word, 1–24 characters,
no whitespace, no trailing newline, no BOM — then verifies the written
file byte for byte.

```sh
node main.ts
cat /output/entry.txt
```
